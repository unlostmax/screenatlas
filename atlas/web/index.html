          Codex generates design references. ScreenAtlas organizes and reviews
          them. Image generation must be available in your Codex session, or you
          can supply PNGs. ScreenAtlas does not call an image service or require
          an API key.
        

        

          Start a different project
          

            Keep each app in its own map folder. From your ScreenAtlas
            environment, run:
          

          
screen-atlas start /path/to/new-map --name "My app"

          

            Your app's code can live in another folder. The demo is an example,
            not a required template or a fixed set of tabs.
          

        

        
Find your way

        

          Drag the canvas to pan. Scroll to zoom around the pointer.
          Shift-scroll pans. Use checkboxes to show or hide groups and
          individual screens. Group names focus the canvas; arrows only expand
          the sidebar. Double-click a card to inspect images. Edit layout
          enables card dragging; the screen editor also exposes placement
          fields.
        

        

          The overview shows the main flow. Select a screen to explore outgoing
          connections, then switch to Incoming or All. Hover or focus an action
          to isolate its arrow. Fit connections shows the related screens.

Local by design

        

          Your project files hold curated references and contracts. The local
          review store holds feedback, proposals, screenshots, and exact image
          versions. Browser storage holds drafts and view preferences only. Keep
          full private backups; read-only exports exclude review content unless
          you explicitly include it.
        

        

          The installation includes an agent skill and JSON command interface.
          The README explains imports, promotion, backup, export, and recovery.
