# ScreenAtlas screenshots

These are browser captures of the working local tool. Onboarding captures use
a new empty app map; the map captures use the Second Sole example. The mobile
images are supplied or generated design references, not screenshots of an
implemented marketplace.

- `getting-started.jpg`: the first-use guide with its project-specific Copy Codex prompt action.
- `empty-project.jpg`: a new app map with a clear Codex entry point and manual alternative.

- `map-overview.jpg`: the default five-tree canvas, with 20 nodes in six groups
  and 14 main-flow arrows; the README hero. All 61 connections are preserved
  and available when a screen is selected.
- `connections-detail.jpg`: selected-screen outgoing actions and routes.
- `connection-focus.jpg`: one action isolated with its source and destination.
- `home-tree.jpg`: Home branches down through listing detail and checkout.
- `profile-flow.jpg`: focus on seller management within the shared canvas.
- `shop-flow.jpg`: the Search tab above its filters branch.
- `reference-review.jpg`: the exact supplied listing action sheet in the viewer.

The underlying PNG references and exact prompts are bundled under
`atlas/examples/second-sole`. Brand names in the illustrative sneaker designs
identify example products; they do not imply affiliation with ScreenAtlas.
